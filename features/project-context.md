This application is a Progressive Web App for coffee farm traceability.

Technology Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Google Apps Script
- Google Sheets

Architecture

Feature-based architecture.

All development must follow:

docs/architecture.md

Each feature contains:

feature.md
workflow.md
design.md
api.md
test.md

Implementation tasks are stored in

/tasks

Master Data is language independent.

Google Sheets stores only codes.

UI supports English and Kannada.

The application must be mobile-first.

Do not rewrite existing working code unless required.

Refactor the existing project to implement a task. Reuse existing code wherever appropriate. Do not recreate files that already exist unless necessary.
